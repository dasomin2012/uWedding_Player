## 1. 작업 목표

### 1.1 수용 기준 (Acceptance Criteria)

1. **신규 파일**: `src/novastar/NovaStarController.{h,cpp}` 추가. `QObject` 상속, public slot `callPreset(const QString& presetId)`, no-op 구현(로그만 출력).
2. **Settings 확장**: `NovaStarConfig`에 `defaultPresetId` 필드 추가(임시 매핑). `settings.json`의 `novastar.default_preset_id` 키와 load/save 양방향 대칭. 빈 문자열이면 비활성으로 간주.
3. **Application 와이어링**: `engine == "obs"` 경로에서 `m_obsBackend->transitionEnded` → `m_novaStar->callPreset(presetId)` 연결. presetId 출처는 §2.3 정책 따른다.
4. **qt 백엔드 경로**: `LiveWindow`(qt)에서도 take 완료 시점에 동일한 콜이 가능하도록 — `TakeController::taken(int)` 시그널에 연결하는 별도 핸들러를 만들어 `engine == "qt"` 경로에서 사용. **OBS 폴백 시점에도 NovaStar 콜은 계속 유지**되어야 함.
5. **CMakeLists.txt**: 신규 `src/novastar/*` 소스를 빌드 타겟에 포함. 게이팅 없음(항상 빌드).
6. **GPL 격리**: 신규 코드는 Qt 표준만 사용(`QObject`, `QTcpSocket`/`QUdpSocket`은 본 단계에서 미사용, 후속). OBS 헤더 참조 절대 금지.
7. **빌드**: `cmake --build build --config Release` 무경고/무에러.
8. **동작 무변경**: `novastar.enabled = false` 또는 `default_preset_id`가 빈 문자열이면 종전과 완전히 동일(로그도 최소화).

### 1.2 비-목표 (이 핸드오프 범위 밖)

- 실 NovaStar TCP/UDP 프로토콜 구현 (후속 Phase 6 별도 트랙).

## 2. 설계 결정

### 2.1 NovaStarController 인터페이스

```cpp
// src/novastar/NovaStarController.h
#pragma once

#include <QObject>
#include <QString>

#include "app/Settings.h"   // NovaStarConfig

namespace uwp {

// NovaStar H 시리즈 LED 컨트롤러 동기 제어.
// 본 단계(O5)는 인터페이스 + no-op 스텁. 실 TCP/UDP 프로토콜은 후속.
// OBS/Qt 어느 백엔드에서도 take 완료 시점에 callPreset()을 부르면 된다.
class NovaStarController : public QObject {
    Q_OBJECT
public:
    explicit NovaStarController(const NovaStarConfig& cfg,
                                QObject* parent = nullptr);

    bool isEnabled() const { return m_cfg.enabled; }

public slots:
    // presetId 가 빈 문자열이면 no-op. 실제 LED 전환은 후속 구현.
    void callPreset(const QString& presetId);

signals:
    void presetCalled(const QString& presetId);
    void presetFailed(const QString& presetId, const QString& reason);

private:
    NovaStarConfig m_cfg;
};

} // namespace uwp
```

```cpp
// src/novastar/NovaStarController.cpp
#include "NovaStarController.h"

#include <QDebug>

namespace uwp {

NovaStarController::NovaStarController(const NovaStarConfig& cfg,
                                       QObject* parent)
    : QObject(parent), m_cfg(cfg) {}

void NovaStarController::callPreset(const QString& presetId) {
    if (presetId.isEmpty()) {
        return;  // 매핑 미설정 — 조용히 무시.
    }
    if (!m_cfg.enabled) {
        qDebug() << "NovaStar: disabled — skipping preset" << presetId;
        return;
    }
    // O5: no-op 스텁. 후속 트랙에서 TCP/UDP 전송 구현.
    qInfo() << "NovaStar: callPreset(stub) presetId=" << presetId
            << "→ host=" << m_cfg.host << ":" << m_cfg.port
            << "protocol=" << m_cfg.protocol;
    emit presetCalled(presetId);
}

} // namespace uwp
```

### 2.3 presetId 출처 정책 (본 단계 임시)

CLAUDE.md 스키마는 Program별 `novastar_preset_id`를 정의하지만 ProgramRepository가 아직 없다(Phase 5 미착수). 본 단계는 **settings 단일 default presetId**를 사용:

- 출처 우선순위: 환경변수 `UWP_NOVASTAR_PRESET` > `settings.novastar.default_preset_id` > 빈 문자열(no-op).
- Phase 5에서 ProgramRepository가 들어오면 `Application`에서 "현재 program의 preset_id" 룩업으로 대체. 인터페이스(`callPreset(const QString&)`)는 그대로 유지되어 호출 측만 바뀐다.

Application에 helper 추가:

```cpp
// Application.cpp (private helper)
QString Application::currentNovaPresetId() const {
    const QString env = qEnvironmentVariable("UWP_NOVASTAR_PRESET");
    if (!env.isEmpty()) return env;
    return m_settings.novaStar().defaultPresetId;
}
```

### 2.4 Application 와이어링

`Application.h` 멤버 추가 (`m_takeController`보다 **앞에** 선언 — 역순 소멸 규칙: NovaStar는 take보다 나중 소멸):

```cpp
class NovaStarController;
// ...
std::unique_ptr<NovaStarController> m_novaStar;  // m_takeController 보다 위
```

`Application.h` private helper 선언:

```cpp
QString currentNovaPresetId() const;
```

`Application.cpp::initialize()` — **sink 결정 직후, TakeController 생성 직전**에 NovaStar 생성:

```cpp
// ----- NovaStar 동기 (O5) -----
m_novaStar = std::make_unique<NovaStarController>(m_settings.novaStar(), this);

// ----- Take (Preview SceneModel -> Live) -----
m_takeController = std::make_unique<TakeController>(...);  // 기존 그대로
// ... 기존 connect 들 ...

// OBS 백엔드: transitionEnded → NovaStar (정확한 LED 동기 타이밍)
#if defined(UWP_HAS_OBS)
if (useObs && m_obsBackend) {
    connect(m_obsBackend.get(), &ObsLiveBackend::transitionEnded,
            this, [this]() {
                m_novaStar->callPreset(currentNovaPresetId());
            });
}
#endif

// qt 백엔드: taken(n) → NovaStar (qt take 는 동기적이라 taken 시점에 호출해도 무해)
connect(m_takeController.get(), &TakeController::taken,
        this, [this](int) {
            // OBS 경로에서는 위 transitionEnded 가 정확한 타이밍을 담당하므로
            // qt 경로에서만 트리거. (engine 분기는 sink 식별로 — 단순화 가능)
            if (m_settings.engine().compare(QLatin1String("qt"),
                                            Qt::CaseInsensitive) == 0) {
                m_novaStar->callPreset(currentNovaPresetId());
            }
        });
```

**O6-A 폴백 경로와의 상호작용:** `installQtFallback()`은 sink를 LiveWindow로 바꾸지만 `m_settings.engine()`은 "obs"로 남는다(파일에 기록된 값). 그래서 위 qt 트리거(`engine == "qt"`) 조건이 **폴백 후에는 발동 안 함**. 대신 폴백 직후의 응급 take도 NovaStar를 한 번 콜해야 한다 → 아래 §2.5의 추가 처리.

### 2.5 O6-A 폴백과의 통합

`installQtFallback()` 안에 NovaStar 콜 한 줄 추가. 위치는 §4(즉시 take) 뒤:

```cpp
// 4) 현재 Preview 를 즉시 다시 take (Live 검정 회피 — best-effort)
if (m_takeController) m_takeController->take();

// 4-O5) 폴백 take 에 대해서도 NovaStar 전환 (LED 동기 유지).
if (m_novaStar) m_novaStar->callPreset(currentNovaPresetId());
```

이로써 qt 정상 경로, OBS 정상 경로, OBS→qt 폴백 경로 3가지 모두 NovaStar 콜이 1회 발생.

## 5. 검증 시나리오 (사용자 측 런타임)

`data/settings.json`에서 다음을 임시로 설정:

```json
"novastar": {
  "enabled": true,
  "host": "192.168.1.100",
  "port": 5200,
  "protocol": "udp",
  "default_preset_id": "P1"
}
```

또는 환경변수:

```powershell
$env:UWP_NOVASTAR_PRESET = "P1"
```

검증:
1. qt 백엔드(`engine=qt`) — Take 1회 → 로그 `NovaStar: callPreset(stub) presetId="P1"` 1회.
2. OBS 백엔드(`engine=obs`) — Take 1회 → `SceneTransitionEnded` 수신 후 동일 로그 1회.
3. 폴백 시나리오 — OBS 강제종료 → `qt fallback installed` → 폴백 take에 대해 동일 로그 1회.
4. `default_preset_id`를 빈 문자열로 두고 `UWP_NOVASTAR_PRESET`도 없으면 — 로그 없음(no-op).
5. `enabled=false`로 두고 presetId를 채우면 — `NovaStar: disabled — skipping preset` 로그.

## 6. 리스크 / 결정 필요 사항

1. **시그널 중복 발화**: `engine=obs`에서 `transitionEnded`가 emit되는 동시에 `taken(n)`도 emit된다. 둘 다 NovaStar 콜에 연결하면 1 take당 2회 콜이 됨. → §2.4의 qt 분기 조건(`engine == "qt"`)으로 이중 호출 방지. 단 폴백 후 `engine` 값과 실제 sink 불일치가 있어 의도대로 동작하는지 코드 정독 필요.
2. **OBS 폴백 후 후속 take의 NovaStar 콜**: 위 §6-1과 같은 이유로, 폴백 후 일반 Take 버튼을 누르면 `taken(n)`은 emit되지만 `engine`이 "obs"라 NovaStar 콜이 발동 안 됨 → 후속 take에서 LED가 안 바뀌는 회귀 가능. **대안**: 별도 멤버 `bool m_qtFallbackActive`를 두고 `installQtFallback()`에서 true로 세팅, `taken(n)` 핸들러는 `engine == "qt" || m_qtFallbackActive`로 분기. 이 대안 채택 권장.
3. **Phase 5 도입 시 마이그레이션**: ProgramRepository가 들어오면 `currentNovaPresetId()` 구현이 settings 단일 default → "현재 program 의 preset_id" 룩업으로 바뀐다. 인터페이스는 그대로라 호출부 변경 없음. 본 단계에서 helper로 격리해두면 마이그레이션 비용 최소화. ✓
4. **GPL 무관**: NovaStar 코드는 우리 IP. OBS 헤더 미포함 확인 — `#include "obs*"` 일체 금지.
